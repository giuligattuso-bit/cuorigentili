# Lámine programmate (non pubblicate)

Questo ramo contiene le lámine da colorare del sabato che non sono ancora online.
Il workflow `.github/workflows/pubblica-laminas.yml` del ramo `main` copia ogni
sabato alle 09:30 (ora di Madrid) la lámina della settimana sul sito.

- `laminas/manifest.json`: data, titoli e descrizioni in ES/EN/IT, percorsi dei file
- `laminas/files/<data>/`: i file da pubblicare, con gli stessi percorsi del sito
